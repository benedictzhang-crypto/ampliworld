# AmpliWorld 世界资产库

## 目的

世界中的楼、船和车不再是临时摆放的匿名物体。每个可复用资产都拥有稳定编号、类别、实现方式、来源、尺度和当前状态。当前浏览器场景以这些编号和对应模型定义建立绑定；后续会把仍分散在场景组件里的路径全部收口到 Catalog。同一资产可以继续关联室内空间、所有权、价格、维护记录和玩家交易历史。

运行时唯一事实来源位于 `web/app/world-asset-catalog.ts`。本文件说明命名规则与美术边界，不重复维护另一份容易失真的清单。

云端生成的原创场景母版保存为 `web/public/visuals/ampliworld-world-asset-master-v1.png`。它是建模方向与质量基准，不冒充当前浏览器原型的实时截图。

CBD 的原创精品商业外立面保存为 `web/public/visuals/ampliworld-luxury-retail-facade-v1.jpg`。新的四面模块化外立面保存为 `web/public/visuals/ampliworld-modular-facade-v1.jpg`，已用于 4S、医院、警务、学院、生鲜商业、中层住宅与通用城市建筑的四个立面，不再只在正面贴一张图。步道、码头和水面使用本地托管的 PBR 贴图；来源与许可保存在 `web/public/assets/pbr/README.md`，运行时不会向第三方素材站请求资源。

昼夜天空的原创透明云层素材保存为 `web/public/assets/sky/cloud-soft.png`。它只提供云团的透明形态，位置、速度、密度、黎明/黄昏染色与夜间暗化均由实时天空系统计算；运行时不依赖外部云图 CDN。

## 美术与知识产权原则

- 现实游艇与建筑图片只用于研究比例、甲板层级、窗线和材料语言，不能把制造商照片抠图后直接放进游戏。
- 最终可识别资产必须是原创、获得明确许可，或来自项目已记录许可的本地模型包。
- 现实品牌名、商标、船型名称和车标不进入资产文件；AmpliWorld 使用自己的编号和虚构名称。
- 近景船按“一个世界单位约等于一米”校准整体长度，大型船放在远海，避免 45 英尺快艇与 100 英尺游艇看起来同样大。`A55` 与 `A60` 目前使用同一款许可原型船壳并以不同尺度表达两个级别，原创模型完成后将分别替换，稳定编号不变。
- 外立面和室内空间使用同一个 `BLD-*` 主编号；室内以后增加子编号，例如 `BLD-B01-I01`。

## 设计参考边界

游艇比例研究参考了公开制造商产品页，包括 Sunseeker Predator 55、Manhattan 55、Azimut 45–100+ 英尺产品序列与 Princess F-Class。参考内容仅用于理解长度、飞桥、挡风玻璃和甲板组织，最终资产保持原创且无品牌。

建筑设计以全球住宅类型为构图参考：现代中式院落强调白墙、深色木构与内院；英式住宅强调坡屋顶、石材和烟囱；美式现代住宅强调宽檐、玻璃面与车行庭院；混凝土住宅、白木住宅、田园住宅与赛博住宅分别建立独立材料和轮廓语言。
