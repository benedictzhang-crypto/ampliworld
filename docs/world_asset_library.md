# AmpliWorld 世界资产库

## 目的

世界中的楼、船和车不再是临时摆放的匿名物体。每个可复用资产都拥有稳定编号、类别、实现方式、来源、尺度和当前状态。当前浏览器场景以这些编号和对应模型定义建立绑定；后续会把仍分散在场景组件里的路径全部收口到 Catalog。同一资产可以继续关联室内空间、所有权、价格、维护记录和玩家交易历史。

可复用建筑、车辆和船舶资产的运行时事实来源位于 `web/app/world-asset-catalog.ts`；住宅社区的规划事实来源位于 `web/app/world-neighborhoods.ts`。前者回答“这个模型是什么、如何渲染”，后者回答“这个社区在哪里、服务谁、处于什么阶段”。本文件说明两套目录的命名规则、美术边界与完成度口径，不重复维护另一份容易失真的逐项清单。

云端生成的原创场景母版保存为 `web/public/visuals/ampliworld-world-asset-master-v1.png`。它是建模方向与质量基准，不冒充当前浏览器原型的实时截图。

大都会总体规划母版保存为 `web/public/visuals/ampliworld-metropolitan-masterplan-v1.jpg`。它用于统一主河、多中心商圈、住宅带、山地、海湾与港口的空间关系，同样属于概念与建模指导图，不是实时游戏截图，也不代表画面中的每栋建筑已经成为 3D 资产。

CBD 的原创精品商业外立面保存为 `web/public/visuals/ampliworld-luxury-retail-facade-v1.jpg`。新的四面模块化外立面保存为 `web/public/visuals/ampliworld-modular-facade-v1.jpg`，已用于 4S、医院、警务、学院、生鲜商业、中层住宅与通用城市建筑的四个立面，不再只在正面贴一张图。步道、码头和水面使用本地托管的 PBR 贴图；来源与许可保存在 `web/public/assets/pbr/README.md`，运行时不会向第三方素材站请求资源。

昼夜天空的原创透明云层素材保存为 `web/public/assets/sky/cloud-soft.png`。它只提供云团的透明形态，位置、速度、密度、黎明/黄昏染色与夜间暗化均由实时天空系统计算；运行时不依赖外部云图 CDN。

## 大都会扩展与完成度

`web/app/world-neighborhoods.ts` 已登记 31 个原创住宅社区，覆盖 5 个产品层级：`VALUE`、`MID_MARKET`、`MOVE_UP`、`PREMIUM`、`TROPHY`；覆盖 7 种住宅类型：`STUDIO_TOWER`、`MID_RISE_APARTMENT`、`HIGH_RISE_APARTMENT`、`SKY_DUPLEX_TOWER`、`TOWNHOUSE`、`SEMI_DETACHED`、`DETACHED_VILLA`。每条记录包含原创名称、区域坐标、目标户数、楼层与高度、商业锚点、地铁站、参考语汇、简述和完成度状态。

这 31 个社区不是 31 套已经完成的 3D 楼盘。当前目录分为 8 个 `PLAYABLE`、9 个 `SHELL` 与 14 个 `PLANNED`：

| 层级 | 资产口径 |
| --- | --- |
| Catalog | 已有稳定规划记录和地图位置，不自动意味着存在近景几何 |
| `PLANNED` | 已定义产品、位置、交通与商业关系，尚未完成可宣称的近景模型 |
| `SHELL` | 已有或预留建筑体量、道路、景观或公共空间外壳，尚缺完整室内、玩法、单位资产或碰撞 |
| `PLAYABLE` | 所在详细区块与代表性空间可进入；仍不等于社区内每栋建筑、每套住宅和每项功能都可进入 |

`web/app/urban-expansion.tsx` 提供本轮新增的程序化城市构件：主河与支流、连续滨水步道、桥梁、北京式地铁入口、分层住宅组团，以及带酒店、码头和多尺度船舶的海湾游艇区。这些构件建立可重复部署的城市语法，后续仍需逐区补齐稳定资产编号、精细碰撞、LOD、室内与玩法绑定。

本轮大都会布局采用三层参考语汇：北京的轴线、环路、轨道生活圈和多中心秩序；洛杉矶的多商圈、长距离城市结构与低密地区；纽约的高密街区基座和修长住宅天际线。主河的连续公共岸线吸收芝加哥、波士顿与上海的滨水经验。海湾游艇酒店、公共海滨、会所和不同尺度船舶以三亚度假海湾的功能组合为研究对象。以上均为比例、结构与使用方式参考，不是地图、项目名称或建筑外形的复制。

## 美术与知识产权原则

- 现实游艇与建筑图片只用于研究比例、甲板层级、窗线和材料语言，不能把制造商照片抠图后直接放进游戏。
- 最终可识别资产必须是原创、获得明确许可，或来自项目已记录许可的本地模型包。
- 现实品牌名、商标、船型名称和车标不进入资产文件；AmpliWorld 使用自己的编号和虚构名称。
- 近景船按“一个世界单位约等于一米”校准整体长度，大型船放在远海，避免 45 英尺快艇与 100 英尺游艇看起来同样大。`A55` 与 `A60` 目前使用同一款许可原型船壳并以不同尺度表达两个级别，原创模型完成后将分别替换，稳定编号不变。
- 外立面和室内空间使用同一个 `BLD-*` 主编号；室内以后增加子编号，例如 `BLD-B01-I01`。

## 设计参考边界

游艇比例研究参考了公开制造商产品页，包括 Sunseeker Predator 55、Manhattan 55、Azimut 45–100+ 英尺产品序列与 Princess F-Class。参考内容仅用于理解长度、飞桥、挡风玻璃和甲板组织，最终资产保持原创且无品牌。

建筑设计以全球住宅类型为构图参考：现代中式院落强调白墙、深色木构与内院；英式住宅强调坡屋顶、石材和烟囱；美式现代住宅强调宽檐、玻璃面与车行庭院；混凝土住宅、白木住宅、田园住宅与赛博住宅分别建立独立材料和轮廓语言。

住宅产品层级可以参考现实项目所代表的空间逻辑，但不能复制其名称、总图、标志性立面或营销表达。北京星河湾用于研究大型园林改善住区的会所、水景、归家序列和大户型尺度；上海汤臣一品用于研究核心滨江高层的景观面、私密落客与大平层组织；北京润园、茂源云紀与北辰红橡墅用于研究联排和双拼的低密秩序；北京紫玉山庄与润泽御府用于研究纯独栋、院落、绿化和安防边界；纽约中央公园沿线超高层用于研究一梯一户、跃层、通高客厅、退台和超细塔身。所有进入游戏的社区名称与可识别建筑必须保持原创。

地铁入口参考北京公共交通的雨棚、下沉楼梯、线路色、出口字母与街角布置，但使用 AmpliWorld 自有标识。一个完整车站应在街区不同方向配置多个入口，并在交通逻辑上连接住宅、商场、医院或学校；单个入口模型上线不等于整座车站、站厅、轨道与换乘系统已完成。

河流和海湾资产必须同时服务景观与经济系统。主河至少要区分公共滨水、居住滨水、文化滨水与港区作业岸线，并保持可步行路径的连续性；游艇区参考三亚湾、亚龙湾与海棠湾的度假功能组合，需要公共步道、酒店、会所、补给与维修、大小泊位，以及渔船、帆船、动力艇、工作艇和大型游艇的合理分区。船舶仍须遵守已有的原创与许可规则。
