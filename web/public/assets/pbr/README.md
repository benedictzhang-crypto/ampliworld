# PBR asset sources

The textures in this directory are self-hosted build assets. They are not fetched from third-party services at runtime.

## Poly Haven — CC0

- `polyhaven/marble_tiles/*`: [Marble Tiles](https://polyhaven.com/a/marble_tiles)
- `polyhaven/cobblestone_floor_04/*`: [Cobblestone Floor 04](https://polyhaven.com/a/cobblestone_floor_04)
- `polyhaven/wood_floor_deck/*`: [Wood Floor Deck](https://polyhaven.com/a/wood_floor_deck)

Poly Haven assets are released under CC0. See [Poly Haven's license](https://polyhaven.com/license).
